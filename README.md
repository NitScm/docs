# nit documentation

The user-facing documentation site for [nit](https://github.com/NitScm/nit), built with
[Astro](https://astro.build) and [Starlight](https://starlight.astro.build).

Everything here is Markdown under `src/content/docs/`. The sidebar is written out
by hand in `astro.config.mjs` rather than autogenerated: reading order matters,
and alphabetical order would bury *filtered projections* — the idea everything
else rests on — behind *Architecture*.

## Running it

```sh
./dev.sh                  # http://localhost:4321
./dev.sh --port 5000      # any astro dev flag is passed through
./dev.sh --host           # expose it on the network
```

The script selects the Node version from `.nvmrc` through nvm, installing it if
it is missing, and runs `pnpm install` when the lockfile is newer than
`node_modules`. Without nvm it falls back to the `node` on `PATH` and says so.

Doing it by hand comes to the same thing:

```sh
nvm use            # reads .nvmrc
pnpm install
pnpm run dev
pnpm run build     # static site into dist/
pnpm run preview   # serve the build
```

## Structure

| | |
| --- | --- |
| `start/` | What nit does, installing, a first workspace, a first policy |
| `concepts/` | Filtered projections, authorization, guards, push and pull, architecture, glossary |
| `guides/` | Policy bundles, server, workers, forges, console, operations, production |
| `reference/` | `nit`, `nitctl`, configuration settings, the HTTP API, error codes |

## Adding a page

Write the Markdown file, then add its slug to the sidebar in `astro.config.mjs`.
A slug in the sidebar with no file fails the build, which is the behaviour you
want.

## Where the content comes from

These pages are written for people integrating nit; the engineering documents in
[nit's `docs/`](https://github.com/NitScm/nit/tree/main/docs) — `ARCHITECTURE.md`, `PROTOCOL.md`,
`POLICY.md`, `CONFIGURATION.md`, `VALIDATION.md`, `DECISIONS.md` — remain the
authority on the internals and on why each design decision was made.

When a flag, setting or error code changes in `nit`, `reference/` here has to
change with it.
